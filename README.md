# FindMyLine

This codebase is owned, written, and maintained by Peter Mascheroni.

## Project Description

FindMyLine began as a sportsbook-focused product for tracking and comparing betting lines. The project is now evolving toward prediction markets, with current development focused on market-style forecasting workflows while keeping core odds and pricing foundations.

## What The App Does

- Tracks market and line movement over time
- Supports user accounts and subscription access
- Provides tools for comparing prices across sources
- Expands from sportsbook use cases into prediction-market use cases

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Security Note

Configuration values, keys, and service credentials are intentionally not documented in this README. Keep all secrets in secure environment management for local and production deployments.
